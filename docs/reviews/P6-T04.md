# P6-T04 Local Performance Measurement

Date: 2026-09-12
Status: Local artifact measurement complete; limited physical-device samples
recorded. The full performance campaign remains pending.

## Method And Result

`assembleRelease` with R8/resource shrinking produced
`app-release-unsigned.apk` at 1,309,831 bytes. The current debug APK is
13,365,498 bytes. The release build completed successfully in 3 minutes
47 seconds in this Windows workspace.

## Limits

Artifact size and host build duration are not startup, memory, callback latency,
device campaign. The successful R8 build emitted Kotlin-metadata compatibility
warnings; investigate the AGP/R8/Kotlin compatibility before signing a public
release if the warning remains.

## Physical-Device Sample

On the Xiaomi Mi MIX 2S debug-build run recorded in
`DEVICE_QUALIFICATION_2026-09-12.md`:

- `am start -S -W` reported a warm activity start of 2,765 ms total and 2,773
  ms wait time. It was not a cold-process result because Android immediately
  recreated the process for the enabled notification listener.
- After moving the UI to Home and waiting 10 seconds, `dumpsys meminfo`
  reported 73,406 KB total PSS, 179,204 KB total RSS, and 0 KB swap.

These are single debug-build samples. Callback latency, burst behavior under
real notification delivery, battery use, release-build memory, and repeat-run
statistics remain pending; no general performance guarantee is inferred.

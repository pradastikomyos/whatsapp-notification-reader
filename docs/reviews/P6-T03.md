# P6-T03 Security And Privacy Review

> Group-catalogue storage described below is historical. It was retired by
> `docs/adr/ADR-013-group-reader-removal.md`; current builds do not retain
> observed group metadata.

Date: 2026-09-12
Status: Local static review passed; physical release verification remains open.

## Reviewed

- Manifest has one launcher activity, a protected non-exported notification
  listener, and a non-exported playback service. Backup and cleartext traffic
  are disabled.
- Permissions are limited to foreground playback requirements; no internet,
  contacts, location, Bluetooth, phone-state, media-control, or DND permission
  is requested.
- Source search found no production logging calls and no network URL use.
- DataStore contains settings only. The retired Room group catalogue is deleted
  on startup; current builds do not retain observed-group metadata.
- Versioned files contain no keystores, tokens, local properties, or secret
  files. Release signing properties are external.

## Remaining Evidence

Verify release artifact manifests, device logs/crash paths, Android settings
backup behavior, and any store crash reporting configuration during the final
campaign. Do not claim a broader on-device-only guarantee without that evidence.

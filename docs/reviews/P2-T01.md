- No model imports Android framework classes.
- Blank IDs/bodies and negative timestamps are rejected.

- Speech requests are constrained to 240 characters.
- Group default is `NO_GROUPS`; reader and riding mode default off/inactive.
- Duplicate suppression is not represented as a reading-policy decision; it
  remains an ingress pipeline outcome per P0-R01.
- No model persists, logs, or serializes message content by itself.

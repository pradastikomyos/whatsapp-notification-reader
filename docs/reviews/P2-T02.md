# P2-T02 DataStore Settings Review

Date: 2026-09-11
Reviewer: OpenCode
Verdict: Passed locally

## Scope

- Preferences DataStore settings repository and application-container wiring.
- Automatic one-time migration from legacy Flutter SharedPreferences.
- ADR-001 migrate/reset behavior and defensive persisted-value decoding.
- Real-file Robolectric integration coverage.

## Checks

- Every read and write triggers migration without caller coordination.
- A mutex serializes concurrent first access and settings writes.
- `flutter.isServiceActive` and `flutter.readPrivateMessages` migrate directly.
- Flutter's encoded `double` prefix is decoded before speech-rate validation.
- Out-of-range legacy rates are clamped; malformed values use the safe default.
- Legacy group selection and riding state are reset instead of inferred.
- Migration is idempotent and reset cannot resurrect legacy preferences.
- Unknown enums, invalid rates, and blank conversation IDs do not terminate the
  settings Flow.
- Tests use `PreferenceDataStoreFactory` and actual temporary DataStore files;
  no mock repository substitutes for persistence behavior.
- No message body, sender name, group name, or raw notification ID is stored.

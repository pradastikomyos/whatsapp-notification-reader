### Corrected during implementation

- Kotlin 2.3 rejects the legacy string `kotlinOptions.jvmTarget`; the build now
  uses the typed `compilerOptions` DSL with `JvmTarget.JVM_17`.
- The official NotificationListenerService sample confirms
  `android:exported="false"` with the signature-level
  `BIND_NOTIFICATION_LISTENER_SERVICE` permission. The old FQCN remains intact
  for grant continuity without exposing the service to ordinary applications.

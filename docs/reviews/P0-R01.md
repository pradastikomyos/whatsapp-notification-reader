# P0-R01 Independent Phase Review

Date: 2026-09-11
Reviewer: OpenCode, independent from the Worker Bee Phase 0 authors
Verdict: Approved with corrections applied during review

## Evidence Reviewed

- Project charter, architecture, implementation plan, and worker prompts.
- ADR-001 through ADR-012 and the consolidated ADR status record.
- Fourteen synthetic JSON fixtures and their documented schema.
- Audio spike source, runbook, summarized ADR evidence, and raw redacted logcat.
- Connected Xiaomi Mi Mix 2S running LineageOS 22.2 / Android 15 API 35.

## Findings And Resolutions

### High: API 35 no-FGS conclusion contradicted official Android behavior

The spike observed audio focus succeeding without an FGS on one LineageOS API
35 device. Official Android 15 behavior states that apps targeting API 35+
must be topmost or running a foreground service before requesting audio focus.
Device-specific success cannot override that contract.

Resolution: ADR-006 now requires a short-lived `mediaPlayback` FGS before focus
on API 35+, with fail-closed startup/promotion/focus handling. The no-FGS path
is limited to API 26-34. The raw observation remains recorded as OEM evidence.

### Medium: Fixture corpus could not test framework extraction

Serialized JSON snapshots can test parsing but cannot verify extraction from
Android `Notification` objects.

Resolution: ADR-003 assigns fixture loading to P2-T04 parser tests and assigns
Robolectric-built framework objects to P2-T03 extraction tests.

### Medium: Conversation catalogue persisted unnecessary direct identities

ADR-004 allowed direct and group rows although v1 only provides group selection.
Persisting direct contact metadata had no product justification.

Resolution: Room catalogue persistence is group-only. Direct identity remains
in memory for parsing, deduplication, and speech formatting.

### Medium: Logging rules permitted raw stable identifiers

Raw shortcut/conversation/notification IDs can be sensitive or correlatable.

Resolution: logs use outcome enums and coarse platform metadata. Correlation,
when essential, uses only an ephemeral per-process salted one-way hash.

### Low: ADR-006 status wording was internally contradictory

Resolution: status is now Accepted as implementation baseline with release
validation explicitly incomplete.

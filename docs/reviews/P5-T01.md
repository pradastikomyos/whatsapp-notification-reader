# P5-T01 Onboarding And Status

Date: 2026-09-12
Status: Passed locally; Phase 5 remains open.

## Delivered

- The onboarding action opens Android's notification-listener settings and the
  activity rechecks access in `onResume` after the user returns.
- The status UI independently observes notification access, listener connection,
  DataStore settings, and TTS engine state. It does not start or stop the
  listener or speech pipeline.
- Reader preference, manual riding state, and Indonesian TTS readiness are
  displayed separately. Before DataStore emits its first value, reader and
  riding status explicitly show loading rather than a guessed default.
- Notification-access lookup failures fail closed instead of crashing activity
  creation/resume. Locale and voice discovery is labeled as an initial TTS
  detection only; a successful test utterance remains authoritative per ADR-011.
- The UI is vertically scrollable for font scaling and uses full-width Material
  controls and resource-backed visible text.
